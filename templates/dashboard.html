Como funciona o fluxo

O prontuário é cadastrado na Unidade de origem, segue para o SOP para organização e conferência, é encaminhado para Contas Médicas e só avança para Pronto para Faturamento quando não existem pendências abertas. O Painel em Tempo Real mostra a posição de cada prontuário nesse fluxo a qualquer momento.
